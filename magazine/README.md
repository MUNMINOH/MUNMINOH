# STOREY 빌딩 매거진 (데모)

빌딩·상업용 부동산 매거진 사이트입니다. 파일 하나(`index.html`)로 동작하며 서버나 빌드가 필요 없습니다.

- 브라우저로 `index.html`을 열면 바로 볼 수 있습니다.
- GitHub Pages, Netlify 같은 정적 호스팅에 그대로 올릴 수 있습니다.

## 구성

| 화면 | 주소 | 내용 |
|---|---|---|
| 홈 | `#home` | 커버 스토리, 최신 기사, 많이 읽은 기사, 이번 주 거래 기록, 시장 데이터, 인터뷰, 투자 가이드 |
| 카테고리 | `#market` `#deal` `#building` `#invest` `#people` `#data` | 층(1F~6F)별 기사 목록 |
| 기사 | `#a1` ~ `#a12` | 본문, 스펙 시트(면적·거래가·평당가 등), 다음 읽을 기사 |

## 기사 고치기

`index.html` 아래쪽 `<script>` 안의 데이터만 바꾸면 됩니다.

- `ARTICLES`: 기사 (제목, 요약, 본문, 스펙 시트)
- `DEALS`: 거래 기록 표 (평당가는 거래가 ÷ 연면적으로 자동 계산)
- `TICKER`, `VACANCY`, `MIX`: 상단 지표 띠와 차트 수치

본문 블록은 문자열(문단), `{ h: "소제목" }`, `{ q: "인용", by: "출처" }`, `{ list: [["제목", "설명"], ...] }`, `{ disclaimer: "안내문" }` 형식을 씁니다.

건물 그림은 사진 대신 기사마다 캔버스로 그리는 입면도 일러스트입니다 (`art` 값: skyline, tower, remodel, section, retail, warehouse, datacenter, campus, chart, bars).

> 기사, 인물, 건물, 거래 내역과 수치는 모두 화면 구성을 보여 주기 위한 가상의 예시입니다.
